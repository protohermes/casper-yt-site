WHAT CASPER DOES

A focused tool with limited access.

Casper YT is operated solely for the channel owner's publishing workflow. It requests only the Google authorization needed to upload videos.

01

Prepares content

Creates finished video files and publishing metadata for review.

02

Uploads securely

Uses Google's OAuth authorization to upload only to the owner's channel.

03

Schedules releases

Schedules approved uploads at owner-selected publication times.

DATA PRINCIPLES

Minimal access. No data sales.

  • ✓ OAuth credentials remain in private server storage
  • ✓ Google user data is not sold or used for advertising
  • ✓ Access can be revoked from the Google Account at any time
